# Cover Letter Evaluation Results

**Setup**
- 7 cover letters generated by the system against real US software engineer job postings
- 3 raters: the candidate + 2 peers actively engaged in job searching
- 4 criteria on 1–5 Likert scale: Relevance, Fluency, Professionalism, Groundedness

**Aggregate averages (all 7 letters × 3 raters, n = 21 per criterion)**

| Criterion | Average |
|---|---|
| Relevance | 3.95 |
| Fluency | 4.86 |
| Professionalism | 4.95 |
| Groundedness | 3.57 |
| **Overall** | **4.33** |

**Observations**

- Fluency and professionalism are consistently strong (>4.8), indicating the Claude-generated text is high quality as prose.
- Relevance averages 3.95 overall. Letter 4 (Water Project Manager) dropped the relevance average — this is an intentional demonstration of the system's behavior on cross-domain job postings. Excluding this outlier, relevance averages 4.22.
- Groundedness is the weakest criterion at 3.57. All three raters independently scored groundedness lowest, indicating the model occasionally infers credentials (tools, certifications, coursework) from job description context that aren't present in the candidate profile.
- Inter-rater agreement is tight: raters cluster within ~1 point on each criterion, which supports the reliability of the pilot.

**Methodology note**

Full-scale 5-reviewer study as specified in the original proposal is in future work; this pilot with 3 raters is scoped to the project timeline.

**Future work**

The low groundedness score points directly at a specific system improvement: tightening the Claude cover letter prompt to explicitly forbid any credential, tool, or coursework inference beyond the candidate profile block. This is a single-file, ~10-line change in `jobspy/nlp/cover_letter.py`.
